# Plugin Exercises — Overview

Here you'll find hands-on exercises for supported Obsidian plugins. Each exercise includes step-by-step instructions, example files, and success criteria.

---

## Prerequisites

- Feature toggle `obsidian-plugin-compat` enabled (Admin → Feature Toggles)
- The respective plugin installed and activated
